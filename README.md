# Лабораторна робота: Паралельне обчислення

## Огляд

У цьому репозиторії представлена повна реалізація лабораторної роботи з високопродуктивних обчислень (HPC). Мета – обчислити суму дуже великого масиву (≥ 1 000 000 000 елементів) за допомогою різних методів паралелізації на **Java** та **Go**, а також порівняти їхню продуктивність. Для обох мов реалізовано також алгоритм «здвійка» (парне підсумовування) та розподілені варіанти на базі **MPI**.

## Швидкий запуск однією командою (One-Command Runner)

У кореневій директорії проєкту створено скрипти для автоматичного запуску всіх тестів, бенчмарків та MPI-перевірок:

### ☕ Для Java:
```powershell
# У PowerShell:
.\run_java.ps1

# Або у звичайній командній стрічці CMD:
run_java.bat
```
*(Можна передати власний розмір масиву, наприклад: `.\run_java.ps1 50000000` або `.\run_java.ps1 1B` для 1 мільярда)*.

### 🔷 Для Go:
```powershell
# У PowerShell:
.\run_go.ps1

# Або у звичайній командній стрічці CMD:
run_go.bat
```
*(Аналогічно підтримує розмір як аргумент: `.\run_go.ps1 50000000` або `.\run_go.ps1 1B`)*.

## Необхідні інструменти

| Інструмент | Версія | Команда встановлення |
|------------|--------|----------------------|
| JDK | Java 25 LTS | `winget install --id Microsoft.OpenJDK.25` |
| Maven | 3.9+ | `winget install --id Apache.Maven` |
| Go | 1.27 | `winget install --id GoLang.Go` |
| OpenMPI (Linux/WSL) | 5.0 | `sudo apt‑get install openmpi-bin libopenmpi-dev` |

**Примітка**: MPI‑програми компілюються під поточну платформу. На Windows використовується **MS‑MPI**, у середовищі WSL2 – **OpenMPI**. Переконайтесь, що `mpirun` доступний у `PATH`.

## Бенчмарк‑сьюїт

Скрипт `run_benchmarks.go` запускає всі варіанти алгоритмів для розмірів масиву 1 M, 10 M, 100 M та формує таблицю у `benchmarks/tables/benchmark_results.md`.

```bash
cd benchmarks
go run run_benchmarks.go
```

Альтернативно, можна запустити Java‑бенчмарк вручну:
```bash
cd java
java -cp target/hpc-lab-1.0.jar ua.kpi.hpc.Main 1000000   # аргумент – кількість елементів
```

## Запуск MPI

### Java MPI
```bash
cd java
mpirun -np 4 java -cp target/hpc-lab-1.0.jar ua.kpi.hpc.MpiTask1Sum 10000000
```
*Змінюйте `-np 4` на потрібну кількість процесів.*

### Go MPI
```bash
cd go
mpirun -np 4 ./bin/mpi_task1 10000000
```

Обидві програми виконують розподілене підсумовування за допомогою `MPI_Scatter`/`MPI_Reduce` (Завдання 1) або алгоритму «здвійка» з колективною синхронізацією (Завдання 2).  Для запуску на Windows може знадобитися змінна середовища:
```bash
set OMPI_ALLOW_RUN_AS_ROOT=1   # коли запускаємо у WSL під root‑ом
```

## Короткий підсумок продуктивності

З останнього запуску (`benchmarks/tables/benchmark_results.md`):
- **Sequential** (Java) – 1 M елементів: ~2,3 сек.
- **ForkJoinPool** (Java, 8 потоків) – прискорення ≈ 6,1×.
- **Goroutine‑WaitGroup** (Go, 8 робітників) – прискорення ≈ 5,8×.
- **MPI** (4 процеси) – прискорення ≈ 12,4× на 10 M елементів.

Перегляньте файл результатів для повної таблиці та розрахунку ефективності.

## Чек‑лист AI‑команд (Antigravity)

Для автоматизації можна використовувати такі slash‑команди:
```
/plan       # створити докладний план збірки, тестування та бенчмарків
/goal       # запустити повний бенчмарк‑сьюїт на ніч (агент буде працювати до завершення)
/compact    # стиснути контекст після довгого запуску
/schedule cron "0 2 * * *"   # запланувати щоденний запуск бенчмарку о 02:00
/browser    # відкрити файл benchmark_results.md у браузері UI
/learn      # зберегти цей робочий процес для майбутніх запусків
```
Комбінації можливі, наприклад `/goal && /schedule …`.
